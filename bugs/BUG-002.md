# BUG-002: Сотрудник (EMPLOYEE) может сам создать заявку на отпуск со статусом approved

| Поле | Значение |
| --- | --- |
| Severity | Critical |
| Priority | High |
| Модуль | Отпуска |
| Связанный кейс | TC-LV-06 |
| Статус | New |

**Предусловия:** Вход под ivanov (роль EMPLOYEE)

**Шаги воспроизведения:**
1. POST /api/leaves/ с токеном ivanov, в теле leave_type, start_date, end_date, employee и "status":"approved"

**Ожидаемый результат:** Заявка создаётся только со статусом pending (поле status недоступно для записи)

**Фактический результат:** HTTP 201, status=approved — самоодобрение отпуска в обход HR. Причина: LeaveRequestSerializer с fields='__all__', status доступен для записи

**Доказательство:** Проверка в Postman: запрос «[TC-LV-06] EMPLOYEE создаёт status=approved» (папка 04 Leaves) возвращает 201 со статусом `approved`. Поле `status` доступно для записи в сериализаторе заявок (`fields = '__all__'`).
