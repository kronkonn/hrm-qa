# BUG-001: Чистая установка по README невозможна: seed_data падает (нет колонки recruitment_candidate.source и таблиц вопросов/ответов)

| Поле | Значение |
| --- | --- |
| Severity | Blocker |
| Priority | High |
| Модуль | Нефункциональные |
| Связанный кейс | TC-NFR-03 |
| Статус | New |

**Предусловия:** Пустая БД PostgreSQL hrm_db, окружение по README

**Шаги воспроизведения:**
1. Выполнить python manage.py migrate
2. Выполнить python manage.py seed_data

**Ожидаемый результат:** migrate создаёт все таблицы и колонки; seed_data завершается успешно

**Фактический результат:** migrate проходит, seed_data падает: ProgrammingError: column recruitment_candidate.source does not exist. Причина: миграция recruitment/0004 помечает source, VacancyQuestion, CandidateAnswer через SeparateDatabaseAndState с database_operations=[] — в БД они не создаются

**Доказательство:** Проверка: установка по README на пустой БД. `python manage.py migrate` проходит, `python manage.py seed_data` завершается ошибкой `ProgrammingError: column recruitment_candidate.source does not exist`.
